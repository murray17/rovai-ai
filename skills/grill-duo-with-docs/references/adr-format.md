# ADR 判断与通用格式

仓库自己的 ADR 索引、模板、编号、状态和替代规则优先。本文件只提供没有项目规则时的默认参考。

## 创建门槛

只有决定同时满足以下条件才创建 ADR：

1. **难以逆转**：未来改变的成本显著；
2. **缺少上下文会令人意外**：代码本身不足以解释为什么这样做；
3. **存在真实取舍**：确实比较过合理替代方案并因具体理由选择其一。

容易修改、显而易见或没有真实替代方案的结论不要创建 ADR。

## 通用模板

```md
# {简短决定标题}

{用一至三句话说明背景、最终决定和原因。}
```

只有确有价值时再加入状态、考虑过的方案或后果。编号时扫描现有 ADR 并使用下一个序号；不要改写历史 ADR 来隐藏一次新决定。
