# Mode: Taste First Redesign

Default mode for redesigns, visual upgrades, dashboards, query pages, personal sites, portfolios, landing pages, and any UI generation task where the user has not explicitly confirmed taste direction.

An execution request is not a taste decision.
If the user says "generate a personal website from my resume" without naming a style, audience impression, or visual direction, use this mode and stop at the taste direction investment gate.

## Load

- `taste/taste_exploration.md`
- `taste/anti_generic_rules.md`
- `references/catalog.md`
- `formats/PROJECT_DESIGN.template.md`
- `workflows/variation_first.md` when direction is uncertain
- `eval/ui_result_critique.md`

## Behavior

1. Read project context.
2. Produce a taste readout before references.
3. Stop for project understanding investment gate.
4. Propose 1-3 taste directions. References are supporting material, not the thing being confirmed.
5. Stop for taste direction investment gate.
6. Write the project design brief.
7. Stop for design brief investment gate and delivery format.
8. Implement and evaluate.

Prefer a better product fit over a louder redesign.
