# Mode: Production UI Implementation

Use only when the user already confirmed a design brief, design system, screenshot, mockup, or explicit taste direction.
Do not use this mode just because the user asked to generate or implement a UI.

## Load

- `workflows/implementation.md`
- `workflows/verification.md`
- `eval/ui_result_critique.md`

## Behavior

- Implement the confirmed design.
- Preserve project architecture.
- Do not reopen taste exploration unless implementation reveals a design flaw.
- Verify and critique before handoff.

## Not Enough For This Mode

These requests still require `taste_first_redesign` unless the user also gives a taste direction:

- "generate a personal website from my resume"
- "build a dashboard"
- "make a landing page"
- "optimize this query page"
