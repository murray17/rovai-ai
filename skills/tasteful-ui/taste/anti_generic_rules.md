# Anti-Generic Rules

These rules prevent reference-led work from collapsing into template UI.

## Avoid

- dark dashboard by default
- oversized hero title on operational tools
- decorative gradient blobs, bokeh, abstract glows, and meaningless atmosphere
- card grids used as filler
- one-note palettes
- fake metrics or invented sections
- generic "modern / premium / sleek" language without implementation meaning
- copying brand-specific colors, shapes, typography, logos, or proprietary patterns
- adding visual weight to elements that are not important to the task

## Preserve

- the product's strongest identity cue
- the user's primary task
- real data shape
- existing terminology that users recognize
- useful density and scanning patterns
- accessibility and interaction states

## Taste Guardrail

If the design would look impressive in a portfolio screenshot but make the product less clear, reject it.
