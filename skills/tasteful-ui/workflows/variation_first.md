# Variation First Workflow

Use when taste direction is uncertain or the surface is visually important.

## Process

1. Produce 2-3 directions before implementation.
2. Make each direction differ by meaningful taste axes, not decoration.
3. Include one conservative direction close to existing product identity.
4. Include one reference-led direction.
5. Optionally include one bolder interaction or layout direction.
6. Score each direction with `taste/taste_critic.md`.
7. Recommend one direction and ask the user to choose.
