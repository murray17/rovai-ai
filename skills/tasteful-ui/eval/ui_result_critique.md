# UI Result Critique

Use after implementation or when ranking screenshots.

## Scorecard

Score 1-10:

- Product fit
- Task clarity
- Hierarchy
- Information density
- Visual taste
- Craft quality
- Accessibility/readability
- Responsiveness
- Originality without imitation

## Failure Conditions

Flag as failure even if the code works:

- chart labels overlap
- text overflows controls
- dark theme hurts readability
- reference style overwhelms product identity
- the UI looks more designed but less useful
- user task is harder to complete
- mobile layout is cramped or broken
- the result looks like a generic template

- Overall score:

- Worst part:
- Better than original:
