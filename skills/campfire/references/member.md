# Campfire 参与者指南

收到另一位 Camp 成员的篝火讨论邀请、定向回应或澄清请求时读取本文件。

始终回复邀请你参与讨论的成员。不要自行选择另一位收件人，也不要把回应转发给其他参与者。需要确认发送方式时运行：

```text
rovai send --help
```

使用与当前阶段一致的自然标题。发送成功后结束当前回复，等待后续邀请。

## 独立开场

只根据邀请中的话题、分配视角和共同事实形成判断。即使公共 Camp 历史已经出现同场其他人的开场，也不要引用或跟随；保留自己的独立判断。

```markdown
### 篝火讨论 · 开场观点

**话题**

> <当前话题>

**核心判断**

<1–2 句>

**主要依据**

- ...
- ...
- ...

**最担心的失败方式或限制条件**

<最重要的一项>

**希望其他成员回应**

<一个真正影响结论的问题>

**置信度**

高 | 中 | 低
```

给出公开、可检查的简要依据。证据不足时直接说明，不补造事实。

## 定向回应

只回应请求指出的一个分岔点，不重新写完整报告。

```markdown
### 篝火讨论 · 定向回应

**话题**

> <当前话题>

**回应的分岔点**

<对方的观点或问题>

**我的判断变化**

维持 | 修正 | 条件性支持

**更新后的核心判断**

<1–2 句>

**关键依据**

- ...

**仍未解决的分歧**

<已解决时写“无”>

**置信度**

高 | 中 | 低
```

证据改变判断时明确修正，不为了维持角色而假装没有被说服。

## 短澄清

Default Lead 只要求确认一句总结时，仅回复：

```markdown
### 篝火讨论 · 澄清

准确。
```

或：

```markdown
### 篝火讨论 · 澄清

建议改为：

> <一条最小、准确的替换句>
```

不要借短澄清开启新一轮讨论。
