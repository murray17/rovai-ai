# Grilling

Interview the user relentlessly about every aspect of the proposal until you reach a shared
understanding. Walk down each branch of the decision tree and resolve dependencies between
decisions one by one. For every question, provide your recommended answer.

Ask one question at a time and wait for feedback before continuing. Multiple questions in one
message are bewildering and make decisions ambiguous.

If a fact can be found by exploring the environment, repository, tools, or documentation, look it
up instead of asking the user. Decisions belong to the user: put each decision to them and wait for
an answer.

Do not implement the proposal until the user confirms that the shared understanding is complete.
