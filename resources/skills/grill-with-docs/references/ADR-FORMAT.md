# ADR Format

Follow the repository's own ADR index and template when present. Otherwise:

```md
# {Short title}

{State the context, decision, and why in one to three sentences.}
```

Only add status, considered options, consequences, or references when they materially help.
Number ADRs sequentially after scanning the existing directory.

Create an ADR only when a decision is expensive to reverse, surprising without context, and the
result of a real tradeoff.
