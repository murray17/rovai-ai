# Grill with Docs

Run the one-question-at-a-time interview defined in
[`references/grilling.md`](references/grilling.md). While decisions are being sharpened, apply the
domain-modeling discipline in
[`references/domain-modeling.md`](references/domain-modeling.md).

Use the included [`CONTEXT-FORMAT.md`](references/CONTEXT-FORMAT.md) when the project has no
stronger glossary format. Use [`ADR-FORMAT.md`](references/ADR-FORMAT.md) only when the repository
does not already define a stricter ADR template or documentation authority.

Repository-local instructions and documentation formats take precedence over the generic
references bundled with this Skill.
