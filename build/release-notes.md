# Rovai AI v0.4.0

**这版重新整理了 Skills 的管理方式。** 旧版在 macOS 会向项目目录添加 Skill 软链接，在 Windows 会复制 Skill 文件；新版不再这样做。升级不会自动删除项目里的旧入口。更新后，可以在「诊断与修复」找到「旧版 Skill 入口」，点击「清理旧入口」；Windows 上遗留的官方 Skill 副本，即使之前没有清理记录，也会显示在这里。正在使用或无法确认归属的内容会保留；如果你曾手动修改旧文件，请先备份。

### 其他更新

- 【功能】**重新整理 Skills 和工具箱。** 可以浏览本机已有的 Skill，按队员选择协作 Skills，也可以在会话中通过 `/` 临时选用。
- 【交互】**补齐移动端会话操作。** 打开侧栏时保留当前会话和草稿；执行过程可从会话顶部查看，记忆、定时任务和设置也有了入口。
- 【功能】**会话历史改为按需查找。** 队员需要早前消息时再读取或搜索；最新消息可以查到，撤回的内容不会出现在搜索结果中。
- 【性能】**会话引导（Charter）更精简。** 收起重复说明，保留处理消息、引用、任务和队友回复所需的规则。
- 【界面】**执行记录减少重复。** 使用 Rovai 内置命令完成操作时，包括通过 Trae CLI 调用，符合条件的命令和操作会合并显示；失败或结果不一致的记录仍分开保留。
- 【修复】**执行详情显示更完整。** Claude Code 的 MCP、Skill 等文本工具结果可以正常查看；历史消息翻页后，执行卡片仍保留原来的标题。
- 【修复】**修复部分运行时首次会话启动失败的问题。** 首轮引导内容可以正常准备，并在后续执行中复用。
- 【修复】**更新 ZCode 接入。** 适配当前官方 App 的模型提供方配置与会话协议，改善模型接入和会话续接。
- 【修复】**改善 Windows 上 Claude Code 的启动。** 多行会话引导和设置改由受管文件传递，避开命令行转义问题。
- 【功能】**本机文件引用不再受单文件 25 MiB 的旧限制。** 文件仍从原位置读取，不会额外复制一份；图片预览的大小限制不变。
- 【修复】**文件变更预览能打开更多实际改动。** 本轮记录的变更文件即使位于执行目录之外，也可以从差异卡片预览。
- 【性能】**创建会话不再等待工作区检查。** 工作区检查转到后台；新建队员后，列表也会更及时地刷新。
- 【功能】**关于与更新页可离线查看当前版本说明。** 发现新版本时，也可以切换查看待更新版本的说明。
- 【修复】**Server 检查更新不再把当前版本误报为新版本。** 下载失败后的官方发布页链接也会指向正确版本。
