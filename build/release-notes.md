# Rovai AI v0.2.2

本次更新带来多段消息引用和个人资料功能，并改善文件变更预览与会话编辑体验。

- **支持多段消息引用**：在同一公屏或单聊中，选取多段消息内容，随新问题一起发送。引用会随草稿、待发送消息及历史消息保留。
- **引用查看与定位更方便**：悬浮查看完整选文，点击回到原消息并高亮对应行；支持逐段移除，清空后自动收起引用区域。修复单聊定位被遮挡、Markdown 列表后选文失败的问题。
- **新增个人资料**：在队员管理中修改自己的名称、上传并裁剪头像。保存后，历史对话中的署名、头像和结构化提及同步更新，消息原文保持不变。编辑页采用简洁的单列表单。
- **新增个人资料卡**：点击会话中的本人头像或结构化提及，即可查看头像与名称；支持键盘操作及快捷关闭。
- **优化文件变更预览**：变更卡片更突出文件名，Diff 差异底色更柔和；窄窗口下支持搜索、滚动和键盘切换变更文件，代码字号跟随外观设置。
- **切换时保留待发送编辑**：在同一窗口切换会话后，返回可继续未保存的正文、成员提及、回复及附件；保存失败保留编辑内容，支持重试。
- **统一会话外观与反馈**：优化浅色与深色模式的雾灰消息配色，复制成功显示勾号，新回复入口与提醒增加提示点。
