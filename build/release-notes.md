# Rovai AI v0.2.4

本次更新新增 ZCode 接入，改善排队消息的执行查看体验，并修复运行监控布局问题。

### 其他更新

- 【功能】**新增 ZCode 运行时。** 支持在 macOS 和 Windows 中接入本机官方 ZCode，读取已有模型与 BYOK 配置，并在队员管理中选择使用。
- 【功能】**ZCode 接入会话与工具协作。** 支持会话恢复、图片读取、文件读写与差异预览，以及 Skills、MCP；同步提供命令行配置、模型查询和可用性检查入口。
- 【修复】**修复排队消息发送后，执行视图仍停留在上一轮的问题。** 停止上一轮执行后，排队消息开始运行时会自动定位到新执行、展开过程并跟随最新内容，同时保留输入框焦点。
- 【修复】**修复运行监控“过去 30 天”的横向溢出问题。** 每日成本明细自动换行，改善窄窗口和高倍缩放下的布局，完整保留日期与金额。
- 【功能】**新增开发者评测与执行分析工具。** 支持执行记录导出和离线报告；macOS 可通过命令行发起任务回归，并关联定时任务。
