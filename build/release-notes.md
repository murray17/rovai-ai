# Rovai AI v0.3.2

这次主要改进了 Camp 删除和工具结果展示。删除操作响应更快，较长的工具输出也不会把本地记录撑得过大。

### 其他更新

- 【升级提示】旧版 Rovai 派发到项目目录的 Skill 入口不会在升级时自动删除。如需自行清理，请逐项核对 `.codex/skills`、`.claude/skills` 等目录，只移除确认由 Rovai 创建且没有运行中的任务使用的旧入口；保留自己添加或归属不明的文件。
- 【性能】**删除 Camp 更快。** 确认后，弹窗会及时关闭，Camp 也会从列表移除；后续清理在后台完成。
- 【修复】**删除中断后可以继续处理。** 如果清理未完成，重启后会继续尝试；仍未成功时会提示重试。
- 【修复】**修复删除 Camp 与工作区准备同时发生时的冲突。**
- 【性能】**超长工具输出会自动截断。** 新产生的普通工具结果超过 7,680 UTF-8 字节后，只保存前段内容并显示省略提示；队员当次执行仍能收到完整结果，文件变更、附件和图片不受影响。
- 【修复】**修复执行过程中的工具结果偶尔消失的问题。** 流式返回的内容会正确保留，MCP 工具返回的附加字段也不会丢失。
- 【界面】**调整桌面端执行视图的间距。** 执行记录更紧凑，浏览时少一些不必要的留白。
