# Rovai AI v0.2.3

本次更新支持自定义项目显示名称，让同名目录下的不同项目更容易区分。

### 其他更新

- 【功能】**支持项目重命名。** 在侧栏项目的三点菜单中选择“重命名”，即可设置此设备上的项目显示名称；仅修改应用内名称，不影响实际文件夹、会话和历史记录。
- 【界面】**项目名称在各入口保持一致。** 修改后，侧栏、置顶、顶部、搜索、定时任务和新建对话中的项目选择器同步显示新名称，重启应用后仍会保留。
- 【交互】**支持恢复目录名与保存失败重试。** 点击“使用目录名”可恢复原名称；输入时提供名称校验，保存失败后可直接重试。
