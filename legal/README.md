# Rovai AI Legal Source Records

This directory retains reviewed dependency licenses, source archives,
provenance notes, and machine-readable snapshots in the source repository.
`THIRD_PARTY_NOTICES.md` is the repository-level entry point.

These files are static source records. The project does not run a legal
generation, preparation, source-check, binary-check, or package-check pipeline,
and macOS packaging does not depend on this directory.

For the MPL-covered `option-ext 0.2.0` component, the relevant repository paths
are:

- `legal/sources/rust/option-ext-0.2.0.crate` — exact unmodified source archive;
- `legal/sources/rust/README.md` — source availability and future-modification policy;
- `legal/licenses/rust/option-ext@0.2.0/LICENSE.txt` — complete MPL-2.0 text;
- `legal/provenance/option-ext-0.2.0.md` — checksum, dependency path, and compliance record.
