# Agent Runtime 未配置：交互稿设计简报

## 产品与任务

- 产品：Rovai AI，多 Agent 本地协作工作台。
- 表面：Camp Composer 的发送失败恢复，以及队员页的运行配置。
- 主要任务：告诉用户哪位队员为什么无法执行，并把用户带到正确的配置位置。
- 成功标准：不暴露内部错误码；消息草稿不丢失；一步进入目标队员的“运行配置”；保存后能返回原 Camp 重试。

## 现有设计约束

- 保留 Arctic Dawn Day 的冷纸白、靛蓝主操作、低饱和状态色与 4/8/12/16/24 间距。
- 产品词汇使用“队员”“Agent 运行时”“运行配置”，不使用“成员”“执行引擎”。
- Core 继续是最终准入真源；Renderer 只解释结构化拒绝并提供恢复动作。
- 可恢复配置问题使用 `attention`，不渲染成数据损坏或危险失败。
- 不使用阻塞 Dialog，不清空 Composer，不增加全局卡片墙。

## 方向与变体

产品应表现为可信、克制、可操作的工作台。参考 Intercom 的支持型文案层级：先说清结果，再说明原因，最后给出单一明确下一步；不复制其橙色、营销排版或品牌几何。

1. 可操作 Toast（推荐）：最轻，适合单一目标的瞬时可恢复错误。
2. Composer 内联提示：错误与发送位置绑定，返回 Camp 后仍容易理解。
3. 目标恢复面板：按目标列出状态，适合多人 Mention，但视觉重量更高。

## 关键文案

- 标题：`小狐狸还不能开始工作`
- 原因：`尚未配置 Agent 运行时。`
- 状态保证：`你的消息已保留，配置完成后可再次发送。`
- 主动作：`配置小狐狸`
- 配置完成：`小狐狸的 Agent 运行时已保存。`

## 交互合同

- 点击“发送”且 Runtime 未配置时，显示所选变体；Composer 内容保持不变并重新获得焦点。
- 点击“配置小狐狸”进入队员页，并直接打开小狐狸的“运行配置”。
- 选择 Runtime 后才能保存；保存成功提供“回到对话”。
- 返回 Camp 后草稿仍在；再次发送成功时清空草稿并进入时间线。
- 原型顶部的方案切换器只用于评审，不进入生产 UI。

## 验证

- 目标视口：1440×920；最小评审宽度：1040px。
- 检查键盘 Focus、长中文文案、错误/成功状态、草稿保留与完整恢复路径。
- 生产落地时应把拒绝结果保留为结构化对象，而不是先压平成字符串。
