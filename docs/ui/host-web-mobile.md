# Host Web 与 Mobile 交互稿

这是供用户评审的第五阶段交互提案。HTML 交互稿随 Camp 附件提供，使用示例数据，不连接 Host、不发送
真实消息，不代表生产能力或 iOS/Android 验收。生产 Web 当前只读范围见 [Host Web v1](../contracts/host-web-v1.md)。

## 现状风格与宽屏实现

延续 Porcelain Day / Steel Night、原生字体、中性会话底色、轻边界和开放平面。Desktop 与 Web 共用
[`theme.css`](../../packages/ui/src/theme.css)，不复制主题数值或按主题分叉业务。
宽屏保持左侧分组导航、中央消息阅读区、资源列表的层级；Desktop 的浏览器开关放在通用设置中，默认关闭。
首次开启显示控制台地址及可临时查看的管理令牌；更换令牌退出现有会话。关闭服务后保留 Desktop 工作状态。

## 手机主要流程

手机在对话列表和当前对话间单列切换，顶部返回与对话名称保持稳定，输入区固定在可视视口底部；
受屏幕键盘和 safe area 影响时不遮住输入与发送。次级工作区通过导航面板进入，不把桌面两栏缩成窄侧栏。
交互稿覆盖 360–430px、横屏和桌面评审画布，两套主题使用同一结构。

| 场景 | 交互与结果 |
| --- | --- |
| Camp 对话 | 顶部返回列表；底部输入、附件、接收对象与发送；切换 Camp 后恢复该 Camp 当前页面草稿 |
| 接收对象 | 在默认、具体队员与全体之间选择；作为草稿的一部分保存，不因 UI 路由自行广播 |
| 成员私聊 | 从成员入口进入独立 Conversation，输入与附件不继承其他 Camp 或 Conversation |
| 附件 | 浏览器文件选择、发送前可移除；使用 source ref；不可用时显示原因，不承诺永久历史下载 |
| 审批 | 显示任务、工具与原生选项；提交期间禁用重复点击；提案中的按钮文案只是样例，生产选项由 Core 提供 |
| 未知发送结果 | 保留原 commandId，禁止再次发送；先查询原回执，确认接受后只消费当时提交的文字和附件 |
| 离线 | 保留输入，禁止发送；不建立离线执行队列；回网重读事实后恢复 |
| 会话过期 | 登录面板覆盖当前工作区，保留当前页面输入；新认证成功后重新核对事实 |
| Task/Memory/Automation | 导航面板切换到单列列表与详情；返回保持当前 Camp 阅读位置 |

按钮触摸目标至少 44px，键盘焦点可见；状态信息不只用颜色表达。低频操作进入 sheet，sheet 的关闭与返回
不能丢弃输入。主题切换不重建业务状态。

## 已做的交互稿检查与剩余验收

自动浏览器检查覆盖日/夜、390/360 宽、横屏、审批、离线与未知回执、独立 Camp 草稿、过期重新登录保留输入。
测试只证明交互稿的本地状态；真实后端草稿归属、跨标签、审批竞争、iOS Safari/Android Chrome 键盘、
后台挂起/网络切换、真实文件上传和两种 Host 入口仍须生产验收。

进入生产实现前需确认移动导航、接收对象选择和审批 sheet 的使用感受；可继续独立后端工作，不要求用户
在休息期间逐项确认。任何交互都不能突破原领域合同和当前 HostCapabilities。
