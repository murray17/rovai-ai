# MCP 与 Skills 设置

使用既有主题 token 和设置导航。内容区为左侧列表、右侧详情的单一工作区，日间保持白底，
夜间沿用 Steel Night。新增、导入、内容预览和删除/更新确认均在右侧完成，不使用应用弹窗。
本地 Skill 的系统文件夹选择器是明确的导入动作，不提供手填本机路径。

MCP 的“添加”和“导入”并列放在左侧标题行，使用相同按钮样式；“导入”提供“从本机导入 MCP”的完整可访问名称。列表只显示已安装项目，不为新建、导入或未保存内容添加占位。

列表把搜索和 `全部 / 已启用 / 已停用` 组合使用。每行首行包含名称、来源标签（Skill）和状态，
第二行显示摘要。开关位于右侧标题旁，停用不删除原有队员或生效组选择。系统必需 Skill 不进入
设置列表、筛选或搜索。搜索无结果时可清除筛选，读取失败时提供简短重试入口。

隔线默认 280px 列表宽，范围 240–460px，并至少给详情保留 360px；实际宽度受窗口约束。
支持拖拽、双击复位、方向键（Shift 加速）、Home/End、Enter 复位和点击增减宽度，Escape 取消
当前拖拽。宽度偏好只保存在窗口本机布局存储。内容区窄于 620px 时切换列表/详情与返回入口，
支持 200% 缩放。调整宽度和切换主题保留当前输入。切换项目、切换 MCP/Skills 或取消时清空未完成的表单，重新进入从空白表单开始，不保存草稿。

MCP 只支持 JSON 编辑，保存复用完整 schema 校验及 digest/CAS。无效 JSON 留在编辑器内；
并发冲突不覆盖当前输入。源文件损坏时阻止写入并提供重新读取/打开修正入口，平时不显示源路径。
从本机导入在右侧扫描并选择候选，默认不选中。候选按右侧内容宽度排列：窄面板一列，
560px 起两列，880px 起三列，随隔线调整自动换列；JSON 在候选内按需展开。
同名项必须显式选择替换或另存为。已有 env/Header 值由后端直接迁移，敏感值默认掩码；
未修改、空白占位或缺省的敏感字段保留原值，掩码不能作为真实值写回，不要求重复填写。
仅当 Core 实际启动环境无法解析引用时，在详情和相应候选内显示“待配置”、变量名称及
“受影响字段”；可先导入为停用配置，不标记为已验证可用。能解析的引用不额外提示。
不兼容引用在折叠的不可导入项内说明具体字段。已存在、不可自动导入与不可读来源折叠说明。
队员分配使用含真实头像的整行按钮，选中填色和勾号表达状态，不使用方形多选框。

Skill 默认展示 [只读内容](../../contracts/skill-content-preview-v1.md)，支持阅读/源码和包内文件切换。
来源标签仅保留 Rovai，包含两个 Grill Duo 改编；GitHub 和本地导入不占用标签位置，来源信息仍保留在
导入流程和 Revision provenance 中。Skill Delivery Group 在页面中称为“生效组”，数量简写为“3 个组”，
全部选中显示“全部组”。生效范围使用整行选择，组内队员显示头像。
首次安装的内置 Skill 与新增 Skill 默认选择全部生效组，启停和更新行为遵守既有 Library
合同，保存过的选择不会被重置。导入先检查、预览，再保存；更新和删除需要右侧的明确确认。
`analyze-agent-codebase` 首次内置安装默认停用；删除 Skill 入口使用红色文字，悬浮时使用浅红背景。

## 验证

`pnpm test:capability-workspace` 在隔离 Electron 中加载真实组件和内存 bridge，覆盖文件夹选择
回调、导入、状态筛选、组选择、JSON 错误/CAS 当前输入保留、敏感值掩码和缺失引用字段提示、原生拖动、并列入口、离开清空和双主题布局。
Skill Library 测试覆盖受管内容读取、遍历/符号链接拒绝、完整性、体积上限和默认组策略。
