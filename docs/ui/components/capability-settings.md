# MCP 与 Skills 设置

使用既有主题 token 和设置导航。内容区为左侧列表、右侧详情的单一工作区，日间保持白底，
夜间沿用 Steel Night。新增、导入、内容预览和更新确认均在右侧完成。删除 MCP 或 Skill 使用
共享应用确认弹窗，默认聚焦“取消”，保留红色“确认删除”。
本地 Skill 的系统文件夹选择器是明确的导入动作，不提供手填本机路径。

MCP 的“添加”和“导入”并列放在左侧标题行，使用相同按钮样式；“导入”提供“从本机导入 MCP”的完整可访问名称。列表只显示已安装项目，不为新建、导入或未保存内容添加占位。

Skills 列表组合搜索和 `全部 / 已启用 / 已停用`，名称旁以状态点和可访问名称表达启停，
只保留 Rovai 来源标签，第二行显示摘要。Skill 开关位于右侧固定标题旁，停用保留生效组。
MCP 不提供启停筛选或开关，只通过使用队员授权；一次提交完整成员集合，非空启用、空集合停用。
新增和本机导入仍默认停用且不分配队员，替换保留原启停与分配。系统必需 Skill 不进入设置列表、
筛选或搜索。搜索无结果只显示简短文本，读取失败时提供重试入口。

隔线默认列表宽 320px，1600px / 2300px 视口分别为 360px / 400px；范围 240–560px，
并至少给详情保留 390px。详情最大宽度随相同断点从 1280px 扩至 1440px / 1680px，实际宽度受窗口约束。
支持拖拽、双击复位、方向键（Shift 加速）、Home/End、Enter 复位和点击增减宽度，Escape 取消
当前拖拽。宽度偏好只保存在窗口本机布局存储。内容区窄于 620px 时切换列表/详情与返回入口，
支持 200% 缩放。调整宽度和切换主题保留当前输入。切换项目、切换 MCP/Skills 或取消时清空未完成的表单，重新进入从空白表单开始，不保存草稿。

MCP 只支持 JSON 编辑，保存复用完整 schema 校验及 digest/CAS。无效 JSON 留在编辑器内；
并发冲突不覆盖当前输入。源文件损坏时阻止写入并提供重新读取/打开修正入口，平时不显示源路径。
从本机导入在右侧扫描并选择候选，默认不选中。候选按右侧内容宽度排列：窄面板一列，
660px 起两列，1060px 起三列，随隔线调整自动换列；JSON 在候选内按需展开。
来源筛选和带 Runtime 图标的标签说明出处；后端使用私有定义确认同名完全相同的候选，通过扫描内
候选 ID 关联，UI 合并展示来源。不能用脱敏 JSON 判断重复。取消、重新扫描、导入集中在固定顶部。
同名项必须显式选择替换或另存为。已有 env/Header 值由后端直接迁移，疑似凭证默认掩码；
详情显式点击“显示”才通过 `mcp.servers.reveal` 读取所选 ID 在预期 digest 下的单项原值，
只保留在当前编辑会话；保存、切换项目或离开页面重新隐藏。JSON 无效时仍可隐藏整个编辑区，再次显示后继续编辑。
原值不进入列表、通用回执或事件；本地存储仍为权限收紧的 `mcp.json`，并非落盘加密。
未修改、空白占位或缺省的敏感字段保留原值，掩码不能作为真实值写回，不要求重复填写。
仅当 Core 实际启动环境无法解析引用时，在详情和相应候选内显示“待配置”、变量名称及
“受影响字段”；可先导入为停用配置，不标记为已验证可用。能解析的引用不额外提示。
不兼容引用在折叠的不可导入项内说明具体字段。已存在、不可自动导入与不可读来源折叠说明。
展开后，每项的名称、带图标的来源和状态组成独立标题行；限制原因和受影响字段在下方显示，
不可并排挤进标题。已知不兼容字段和引用使用中文说明，同一项目内相同原因合并，保留全部字段并允许换行。
队员分配位于 JSON 上方，使用 120×34px、22px 头像的紧凑按钮，不提供队员搜索。
JSON 随内容伸缩，从 142px 至 640px 或视口高度的 58%，不通过重挂载编辑器调整高度。
保存和红色删除在固定顶部，长内容滚动不影响操作可见性。删除弹窗绑定打开时的项目身份和配置版本；
提交中阻止重复确认或关闭，失败保持弹窗与原配置。取消、关闭、Escape 或删除成功后不额外将焦点移回入口；保留弹窗内键盘操作与焦点约束。
常规说明仅按需使用与一键新建相同的问号悬浮组件。

Skill 详情名称旁不显示内部修订号（r1、r2），保留 Rovai 来源标记。默认展示
[只读内容](../../contracts/skill-content-preview-v1.md)，Markdown 使用阅读/源码分段控制，其他文件直接显示原文或既有不可预览状态，
不显示“只读”标签。文件入口为紧凑的当前文件名与相对目录，多文件时显示数量和展开箭头；
点击后在正文上方展开包内目录，按文件夹分层，当前文件带勾。选中文件后收起目录、清空搜索、返回正文顶部，
焦点回到文件入口；单文件仅显示名称。超过 10 个文件才提供搜索，无匹配只显示简短文本。
目录支持文件夹折叠、Tab、上下方向键、Home/End、左右方向键展开/收起文件夹及 Escape 返回入口；
长路径折行或省略，完整相对路径保留在可访问名称和 title 中。文件工具栏随详情滚动保持可见，
正文不另设固定高度。详情与导入预览共用导航，切换 Skill、Revision 或导入候选重置文件、目录与搜索；
迟到的读取结果不得覆盖当前目标。Skill 导入按钮放在左侧标题，
取消/导入或更新集中在右侧固定顶部；GitHub 输入与读取按钮相邻，支持 Enter 读取。
来源标签仅保留 Rovai，包含两个 Grill Duo 改编；GitHub 和本地导入不占用标签位置，来源信息仍保留在
导入流程和 Revision provenance 中。Skill Delivery Group 在页面中称为“生效组”，数量简写为“3 个组”，
全部选中显示“全部组”。生效范围使用整行选择，组内队员显示头像。
首次安装的内置 Skill 与新增 Skill 默认选择全部生效组，启停和更新行为遵守既有 Library
合同，保存过的选择不会被重置。导入先检查、预览，再保存；更新需要右侧的明确确认，删除需要应用弹窗确认。
`analyze-agent-codebase` 首次内置安装默认停用；删除 Skill 入口使用红色文字，悬浮时使用浅红背景。

## 验证

`pnpm test:capability-workspace` 在隔离 Electron 中加载真实组件和内存 bridge，覆盖文件夹选择
回调、导入、状态筛选、组选择、JSON 错误/CAS 当前输入保留、敏感值掩码和缺失引用字段提示、原生拖动、
并列入口、离开清空、固定顶部操作、显式凭证读取/隐藏与迟到响应隔离、GitHub 多候选导入和 2K 双主题布局。
文件导航覆盖目录展开、单文件、多文件搜索、长路径、读取失败重试和迟到响应隔离；不可导入项覆盖同名不同来源、重复原因合并及长字段换行；删除弹窗覆盖键盘焦点、取消、失败重试、提交中关闭拦截和并发版本冲突。
Skill Library 测试覆盖受管内容读取、遍历/符号链接拒绝、完整性、体积上限和默认组策略。
