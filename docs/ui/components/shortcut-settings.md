# 快捷键设置

Desktop「设置 → 快捷键」的侧栏入口位于外观之后；页面使用单行设置与分组侧标题，
分为会话工作区、输入、应用与导航、查找与文件。沿用设置页的 1040px 内容列、主题 Token、标题和中性弹窗。
不提供搜索、系统/编辑分组、重新加载文件或单独鼠标侧键页。

平常按键区外框透明，悬浮与键盘聚焦时显示 1px 边框和输入底色；内部键帽保留。
点击任一动作右侧直接录制键盘或实际鼠标侧键，不经过省略号菜单或编号选择。
键盘与侧键可并存，旁边的清除按钮只删除对应绑定；恢复单项清除该项侧键并恢复默认键盘组合。

录制初始只显示「请按下快捷键」。只按修饰键继续等待；普通字符缺少合法修饰键时才显示：
macOS「请搭配 ⌘、⌃ 或 ⌥ 使用。」、Windows「请搭配 Ctrl 或 Alt 使用。」。
有效候选清除错误；保留组合继续经过现有冲突检查。已保存绑定被占用时明确显示原动作，按钮为「替换并保存」。
Enter 保存、Esc 取消；未收到候选时不常驻 Esc 提示。失焦或离开页面取消录制，不保存候选。
保存失败保留当前候选，在对应设置项旁显示明确错误并保留滚动位置；只有 Main 保存成功才变更显示与实际绑定。
清除键盘或侧键绑定后，成功与失败均恢复当前行的按键入口焦点；用户已主动移到其他控件时不抢回焦点。

执行/队员/单聊/任务默认为主修饰键 + 1/2/3/4。文件区显隐保留标签和阅读位置；执行台显隐保留选择与阅读位置；
聚焦/附件/最新位置使用当前会话或单聊区域。文件查找与会话查找保持各自状态。
侧键默认不绑定，只在用户明确保存后启用。

发送方式提供 Enter 与主修饰键 + Enter。Desktop 公屏和单聊删除常驻输入框发送说明，发送按钮使用动态 tooltip、
可访问名称与 aria-keyshortcuts 显示当前组合；停止、插话/排队模式与提交业务保持原入口。
恢复所有默认值使用现有 AppDialog，明确包含侧键清空和恢复 Enter 发送。

[Desktop Shortcuts v2](../../contracts/desktop-shortcuts-v2.md)拥有字段、校验、并发、输入分发与失败语义。
`pnpm test:shortcut-settings` 以隔离 Electron 窗口检查生产组件和实际键盘事件；
`ROVAI_KEEP_SHORTCUT_FIXTURE=1` 可保留日间、夜间、紧凑宽度和英文截图。此 fixture 不启动 Core/Runtime。

会话任务关闭时隐藏任务动作、计数和键位，不消费其键盘或侧键；仅取消该动作的录制。用户可将隐藏任务绑定分配给其他动作，保存时原子清除旧任务绑定，重新开启不抢回。

偏好升级与兼容规则由 [Desktop Shortcuts v2](../../contracts/desktop-shortcuts-v2.md) 拥有。升级保存失败时显示重试入口，不覆盖原文件。
