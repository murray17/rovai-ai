# Skills、工具箱与会话选择

Skills 设置与工具箱是两个独立入口，沿用 [DESIGN.md](../../../DESIGN.md) 的 Porcelain Day / Steel Night token、全宽双栏布局和既有设置导航。来源、权限和模型投递以 [Skills Rebuild v1](../../contracts/skills-rebuild-v1.md) 为权威；本页只规定用户可见交互。

两页中间分隔线与 MCP 共用拖动行为：左栏最小 240px、最大 560px，并为右栏保留 390px；宽度偏好按页面分别保存。支持方向键（Shift 加大步长）、Home/End 到边界、双击或 Enter 复位、Escape 取消当前拖动。内容区域不足 620px 时切为列表/详情单栏。刷新、查看说明沿用交互稿的 12px、500 字重文字与 15px 线性图标。

## Skills：只读原生来源

顶部选择 Runtime；列表只展示该 Runtime 在执行 Host 的用户级原生 Skill，不混入旧 Rovai Library 导入行或当前项目来源。左栏搜索名称、简介和入口路径，右栏展示说明、可复制入口路径和只读正文。文件栏提供可搜索的树形下拉，在 `SKILL.md` 与同目录普通文件间切换；Markdown 可在阅读和源码间切换，二进制或过大文件显示明确状态。宽屏内容使用可用宽度。刷新只更新候选；切换 Runtime、候选或刷新时，迟到的列表/正文响应不得覆盖当前选择。

Loading、空集合、无搜索结果、部分来源不可读、整次读取失败和正文读取失败分别给出明确状态。部分失败保留已找到的项并允许重试；正文失败保留当前 Skill 和路径。窄窗口在列表与详情间切换，并提供返回列表。来源路径是证据，不构成 Runtime 已加载或模型已读的承诺。

## 工具箱：逐队员配置

左栏固定五项工具箱，显示名称、简介和已选队员数；右栏显示队员配置，“查看说明”弹窗阅读完整受管 `SKILL.md`。宽屏队员列表双列。可搜索队员姓名或角色，单个复选框即时保存。全选/取消全选只作用于当前过滤结果；保存中禁止重复提交并给出状态，失败回滚可见勾选、保留错误和当前搜索/选择，用户可再次操作。`member-studio` 升级和新队员默认开启，用户可关闭；未选择 Skill 的队员仍能正常参与协作。窄窗口从列表进入配置详情后提供返回入口。

## Camp Composer 的 `/` 候选

当前 Camp 的候选包含全队配置的工具箱项及各队员 Runtime 环境可发现的用户/项目原生 Skill。相同名称的不同来源是不同项；候选分为“工具箱”和“Skills”两组，相关队员头像置于行右，来源身份保留在可访问名称中。键盘上下选择、Enter 确认与显式刷新可用。部分来源不可读时保留可用候选；旧引用或暂时失效来源仍作为原消息内容保留并允许发送，状态文字说明其当前不在候选中。已发送的 Skill 引用可打开现有文件预览分栏；失效来源显示失败状态，不按同名项改绑。Picker 不声称某个 Runtime 已加载 Skill。

## 诊断与修复：旧版入口

旧版项目入口只以“旧版 Skill 入口待清理”出现在“需要处理的问题”中，提供统一“清理旧入口”按钮。页面不展示项目清单、逐项目按钮或“项目入口检查完成”提示。点击后在同一问题简要报告清理和保留数量，复检同步更新问题、摘要及完整检查结果；归属不明、不可访问、运行中入口保持原状。
