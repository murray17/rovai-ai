# Camp 文件预览区

## 会话内的文件链接

文件链接保持正文阅读感，使用现有链接色、轻下划线与原生链接语义，不呈现为按钮或 Badge。Hover 加强下划线，
键盘焦点使用既有 focus token；长路径可自然换行，不让正文横向溢出。

- Markdown 文件链接 `[label](target)` 只显示可点击的 label；target 仅用于解析/打开，不在正文中重复常驻展示。
- 反引号包裹的有效文件路径只显示一份路径，保留 inline-code/等宽样式；裸路径继续按高置信度规则识别。
- 链接 title 显示完整原始 target，包括行列或 fragment。复制路径与显示所在位置继续使用文件 Tab 的既有上下文菜单。
- 文件引用按 Markdown 语法节点识别，不拆开普通 URL、链接 label、图片、代码块或其他非文件 inline-code；
  用户消息其余文本、结构化 Mention/Skill、消息存储、整条消息复制与模型输入保持原合同。
- 点击继续使用既有来源校验，打开/激活文件 Tab；同一文件去重，有行号时定位对应行。不支持格式仍调用默认应用。

## 结构与布局

文件预览与会话平级，共用一行紧凑标题栏：左侧显示会话定位及“执行（条件式）/ 任务 / 队员”详情入口，
文件 Tabs 占右侧文件列。详情在会话阅读区内按需浮层展示，不再占用第三列，也没有独立侧栏或文件预览图标。
顶栏使用会话 surface，与正文之间不画横线；列之间只用低对比 workspace divider。会话槽位不显示分享或更多操作。

以扣除左侧导航后的实际工作区宽度计算分栏：默认会话 44%、文件 56%；会话至少 420px，文件稳定宽度至少
420px。工作区不足 841px 时，预览替换整块会话（含输入区），Tab 栏前导显示“返回会话”，不显示拖动手柄。
详情开合不改变两列宽度，标题栏与正文始终共用同一分栏边界。任何模式都不得令应用产生水平滚动。
会话自身宽度不大于 480px 时使用[紧凑会话布局](conversation-workspace.md#会话-pane-紧凑布局)，
不改变主导航、Camp 顶栏或执行台样式，也不因跨越断点重新挂载会话内容。

### 分隔线与比例记忆

- 分隔线视觉宽 1px、命中宽 9px；hover、键盘焦点及拖动时使用 3px Steel，保留安静的居中握柄。
- 向左拖动增大文件区，会话进入 480px 后紧凑排版，直到 420px 时停止；不折叠会话。向右拖动时文件区跟手变窄。
- 文件宽度在 320–420px 时松手，回弹到 420px；小于 320px 时预览降低强调度，分隔线转为 danger，
  显示“松开关闭文件预览”，松手关闭预览。关闭不清空文件 Tab、阅读位置或会话草稿，也不留下独立预览入口。
- Escape、pointercancel、丢失指针捕获或窗口失焦取消本次拖动；容器缩放或切换 Camp 也中止手势，不提交中间宽度。
- 左右方向键调整 24px，Shift+左右调整 80px，键盘调整遵守稳定宽度边界。Delete/Backspace 关闭预览；
  双击分隔线恢复 44/56。关闭后把焦点还给会话阅读区。
- 分隔线使用 `role="separator"`、垂直方向和实时 `aria-valuenow/min/max`，提供键盘说明和关闭提示。
  回弹及重置只使用短过渡，reduced motion 下直接落到目标宽度。

只在稳定拖动提交、键盘调整或双击重置时保存比例，不保存像素宽度。窗口变化时按
`clamp(工作区宽度 × 已存比例, 420px, 工作区宽度 − 420px)` 重算；临时被边界夹紧、紧凑替换、拖动取消或
拖拽关闭都不覆盖偏好。再次点击真实文件引用或 Files Changed 项时，恢复上次稳定比例；无偏好时使用 56%。
布局状态独立于文件内容状态，拖动不要求重新渲染整个 Camp 或 Viewer。

## 文件 Tabs

Tabs 使用 Codex toolbar 语法：小间距、无逐项边框、当前项用次级 surface 和文字对比表达，不使用品牌下划线。
文件名使用 UI 字体；重名时显示 `父目录/文件名`。关闭按钮预留固定宽度：当前选中项始终显示；其他项默认透明且
不响应指针，Tab hover、focus-within 或粗指针环境下显示，因而文件名不位移且键盘/触摸始终可达。

成功打开文件时，只对对应 Tab 提供一次轻量反馈：新 Tab 的文件名在 200ms 内从右侧 6px 原位落定，同时底色
短暂强调；重新打开已有文件只重复 300ms 底色反馈，不创建重复 Tab。目标 Tab 保持在标签栏可见范围，正文、
焦点、滚动位置与其他 Tab 不参与动效。连续打开替换前次反馈；外部更新、读取完成和刷新不重播动画。减少动态效果
时取消位移与闪动，选中底色和常显关闭按钮仍立即表达最终状态。

Tablist 采用手动激活与 roving tabIndex：左右、Home/End 移动焦点，Enter/Space 激活，Delete 关闭，
Alt+Shift+左右重排。关闭后优先激活右侧，再回到左侧；最后一项关闭后返回有效触发器，否则返回会话主阅读区。
后台打开不抢焦点，只用 polite live region 宣布；紧凑替换后把焦点移到当前 Tab。

## 路径与 Viewer

Tabs 下只保留一行只读相对路径和 Viewer。路径格式为 `apps > desktop > … > filename`，整体从左侧自然排列，
文件名紧跟最后一个可见目录，不固定到最右侧。空间不足时从目录中部省略，优先完整保留文件名；无水平滚动。
完整相对路径进入 title 与可访问名称。路径与 Tabs 间无线，路径与正文间一条语义 divider。

Viewer 不显示预览/源码切换、右上角复制按钮、整行工具栏或 `Ready` 状态。每个类型只有一个规范阅读视图：

- Markdown 渲染安全 GFM；超出 4 MiB 显示分页原文；
- HTML 在 sandbox iframe 中执行；超限或初始化失败回退只读原文；
- 代码/文本只读显示行号、搜索、定位、选择与系统复制，大文件分页；
- 图片/SVG 提供适应、原始尺寸、缩放和重置，不把 SVG 注入宿主 DOM；
- Diff/Patch 按文件和 hunk 展示，解析失败回退文本。

Viewer 底色与会话阅读区共用语义 surface。选中文字只保留普通系统选择/复制行为，不出现“附加到会话”浮层，
也不向 Composer 添加引用卡片；引用能力留待后续整体设计。

不支持的 Office、PDF、音视频、压缩包、数据库、可执行文件和未知二进制不进入预览。显式点击继续调用系统默认
应用；当前 Tab、布局和焦点上下文保持不变。

## 更新与错误

首次打开只有 opening/ready/error；快速成功直接显示正文，耗时后才显示轻量 Loading，失败显示“无法打开文件 / 重试”。
外部变化只显示 Tab 圆点与当前 Viewer 的“有更新 / 重新加载”。主动刷新期间旧内容继续显示；失败显示
“重新加载失败 / 重试”且不销毁 Tab。句柄、Grant、token、watcher 和 generation 永远不是用户文案。

## 平台

macOS/Windows 复用同一 DOM、reducer、Viewer 和主题 token，只投影 `⌘/Ctrl`、Finder/文件资源管理器、系统字体和
既有 window chrome 差异。除分隔线使用上述 3px Steel 外，焦点状态使用现有 2px focus token，焦点不得被 sticky 内容完全遮挡。
