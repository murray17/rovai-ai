# Rovai 长期记忆

在“通用设置 → 会话”切换“Rovai 长期记忆”。默认开启；同一 Core 实例连接的 Desktop、Web、
移动端和所有队员共用该设置，覆盖共同记忆、队员记忆和队员间记忆。会话任务使用独立开关。

关闭后暂停队员的后续记忆读写，以及记忆页的查看、编辑、导出、遗忘、审核和复核管理。
已有记忆、修订和待审核项保留；重新开启后可继续使用和管理，已停用或遗忘的记录不会自动恢复。
记忆页的“前往设置”可以返回开启入口。状态暂不可用时使用“重试”，读取失败不表示开关已关闭。

已经进入当前对话上下文的内容仍可能保留。切换不停止现有执行、不重建会话，也不修改或补发已投递输入。
已经提交的操作仍可确认原回执，关闭不会把已保存的事实改判为未保存。
本开关只控制 Rovai 自己的长期记忆；各 Agent Runtime 的原生记忆策略继续沿用。
