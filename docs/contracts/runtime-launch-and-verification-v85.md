# Runtime Launch and Verification v85

继承 [v84](runtime-launch-and-verification-v84.md)。本版只增加本机安装版本按需刷新，以及有可靠版本基线的
Rovai 自有 Host 温和退出复用。检测按钮、模型目录、正式初始化、认证与会话接续各自的职责保持。
不查询远端版本、不下载安装、不修改用户原生配置。

## 按实际目标读取

Run 已选定实际安装与 Host、进入正常执行流程后，可以向现有 Check Manager 提交轻量版本请求。
提交不等待锁、版本命令或其他 Host 关闭；不是创建 Run、获取 Host 或发送输入的前置条件。
仅查询该安装、程序路径与实际捕获的启动环境，不扫描全部 Runtime，不切换安装副本。
同一目标由现有进程内检查记录共享最近实际尝试时间；自动尝试最小间隔十分钟，成功和失败（含实际入口读取失败）均计时。
未到期跳过；没有 Run 就不触发，不增加定时任务或持久化记录。
正式入口被替换或保存新的程序路径时，删除被替换入口的尝试记录；当前入口的不同有效启动环境仍分别限频。
旧读取不能重新建立已删除的记录；切回原路径建立新记录，原选择期间的迟到结果不能写版本或标记 Host。
清理入口记录不删除活跃 Run 已实际读取过版本的事实，该事实沿既有 Run 收尾清理，避免本轮追加查询。

手动检查绕过该间隔。相同目标、用途与既有合并条件匹配时，手动和自动请求共享在途读取。
整体重扫继续原有并行流程，已有正式启动继续原有调用，不为统一所有入口重建调度或强制全局单飞。
本轮正式启动已经实际读取版本时，成功或失败都不追加自动查询；命中历史版本缓存不算实际读取。
手动、重扫及已有正式启动的实际读取均登记尝试和结果顺序，草稿检查除外。

沿用适配器命令、解析、启动环境、容量限制与十秒版本命令上限，不增加重试、认证预检或目录查询。
成功按原有身份围栏保存安装版本。自动失败只记录日志，不改安装可用性、不发布失败诊断、不影响 Run；
同一次读取有手动等待者时，仍向手动请求返回并在原位置展示具体失败。
未保存草稿独立检查，不更新正式安装、不更新正式目标的限频/结果顺序、不触发 Host 退役。

## 结果顺序与可靠基线

实际读取开始时，登记同目标的递增顺序并捕获当时可归属的 Host 基线；提交时在原有安装/入口/配置校验内
核对顺序。较新结果已接纳后，较早结果不得写回版本或标记退役；静态缓存发布也不得覆盖同身份当前已保存的版本。
不比较版本大小，不保存读取历史。换代只响应同一实际目标的可靠版本变化；路径或文件指纹变化本身不构成本功能的换代依据，
原有安装完整性处理不变。

显示用 reportedVersion 可能来自缓存，非空不代表进程真实版本。Host 基线仅取已有启动过程的可靠实际读取，
或该进程的可信自报信息；不得把 Host 启动之后的磁盘查询补记成它的版本，也不增加同步启动查询。
当前 Codex 从 initialize 的 server userAgent 读取构建版本；OpenCode 从已有 initialize 的 agentInfo.version
读取，且必须已有正常冷接续能力、没有已知存储代际冲突。其他来源不明的 Host 保持未知，不因安装行更新而退役。
比较仅对适配器已知的有效版本信息作等值判断，保留原有显示形式及 ACP 版本校验。

退役只匹配读取开始时捕获的目标、Fleet 进程记录与不可变 Host 实例，且其旧版本与新观测不同。
不以“所有版本不等于结果的 Host”为关闭条件。较晚启动的新 Host、其他安装和环境均不属于旧基线集合。
读取失败、空输出、过时结果、未知基线或目标不对应时均不触发本次退役。

## 温和退出复用

沿用 Fleet 进程记录、锁、释放、既有 Sweeper 与 Stop completion，增加独立的温和换代标志，
不改变原有强制取消标志的语义。短锁内标记禁止未来普通复用，锁外检查既有原生静默条件、发起原有清理。
空闲且可关闭的旧 Host 异步关闭，不预热替代进程；当前 Run 或已经接纳的启动不取消、不使启动提交失败。
本轮释放后不能回到可领取的 Warm；仍有已知原生后台工作时保留但隔离，既有清理确认静默后才关闭。
不新增后台工作监控器或强制退役期限。手动检查返回不等待忙碌 Host 完成或 Stop 结束。
同复用范围的旧 Host 已在关闭时，后继获取可以等待它已有的 Stop completion，避免争用原生 Session 锁。

只有具备既有正常冷启动和会话接续路径的 Host 才参与。后继使用当前入口冷启动，沿原有 Native Session
接续，不删除对话、清空历史、把安装版本加入 Session 身份或用空白会话隐藏恢复失败。
Hermes 当前逐 Run 关闭 ACP Client，不作为 Warm 换代证据；共享 Gateway 不在 Rovai 本次关闭范围内。
安装版本更新不回写正在执行的旧 Host/Run 的版本。不保证升级后第一条 Run 使用新版；
外部原地升级损坏旧进程文件、新程序启动或接续失败仍按实际运行结果处理，不自动回滚或切换副本。
