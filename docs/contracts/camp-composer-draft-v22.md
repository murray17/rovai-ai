# Camp Composer Draft v22

继承 [v21](camp-composer-draft-v21.md)。

ComposerDocument 保持 version 2；文件引用变体增加可选 targetKind，缺省 file，新目录 directory。
私有剪贴板、草稿、失败恢复、撤销和输入历史保留类型与原位置；未知类型拒绝，不能按名称猜测。
目录用既有文件夹图标，短标签无末尾 /；完整身份字段不改成短名。单独有效目录也是实际输入。
四个 @ Tab 分开展示；根层不显示辅助路径，桌面 480px，键盘与输入法规则沿用。
字段和预算见 [项目引用 v2](project-file-reference-v2.md)。
