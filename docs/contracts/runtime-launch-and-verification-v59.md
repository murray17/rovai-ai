# Runtime Launch and Verification v59

继承 [v58](runtime-launch-and-verification-v58.md)，以下规则替代会话环境固定、历史环境恢复、
快照引用归属和缺快照拒绝。程序安装、原生配置、权限、协议健康、Run 身份、执行代次、输入确认与重试安全保持。

## 进程启动配置

队员环境仍按 Host＋队员实例＋Runtime 私有保存。真正新建顶层 CLI 时才读取当前宿主进程环境与
当前队员覆盖，同名覆盖、不同名追加；删除队员条目恢复继承，空字符串仍是显式覆盖。再应用 Rovai
内部字段和既有 Adapter 启动配置。只影响目标子进程，不修改 Host 或其他队员；不额外扫描 Shell/.env。
JSON 校验、保留字段、模型规则、值不作 Shell 展开和已选绝对程序路径规则继承不变。

领取 Run 不读取环境。Fleet 命中健康 Warm 时不读取或解密最新队员环境；配置不可读不能阻断旧进程。
创建分支在实际启动时读取，即使 Run 早已领取，仍使用本次启动时的配置。一次启动的内存环境映射
仅供该 CLI 使用；Adapter 后续配置不得重新继承 Host 而反向覆盖队员值。原生文件仍按各 Adapter 既有规则处理。

已有 CLI 派生的终端或工具子进程从现有 ManagedProcess 启动上下文继承，再应用请求允许的覆盖，
不读取最新队员环境。进程退出、崩溃、回收或 App 重启后，新 CLI 使用当前配置；原生历史按既有机制续接。

已有原生绑定若未包含默认 Host 连接身份，当前安装、协议与 Session 权限投影仍精确匹配该绑定时，
继续保留这份不含默认连接的身份，不能因环境读取时机调整而额外混入默认连接、隐式重开会话。
判断只使用既有绑定及当前兼容投影，不读取队员环境或历史环境快照；已有包含默认连接身份的绑定
继续遵循原连接兼容检查。安装、协议、权限、工作目录、归属与主动重置的检查不变。

## 保存、复用与错误

保存或删除 env 只更新私有配置；不停止进程、不重置原生 Session，也不以环境 revision 或队员 version
间接失效 Warm。保留加密、密钥遮蔽、Owner 权限、私有更新回执与并发写入保护。

Fleet 仍限制同一 Camp、同一队员、当前会话和 Runtime；使用现有 native binding 身份隔离显式重置，
不以环境内容或历史 plan_id 决定归属。工作目录、协议、权限、健康、容量、清理与后台消息机制不变。
主动重置仍用于重新开始上下文，不再是应用环境配置的操作；Camp 消息保留。

新 CLI 的队员配置读取失败由现有单 Run 启动失败路径展示；解析无效的单队员运行配置通过现有单 lane
失败记录结算，不中断其他 Camp 的消息领取。数据库查询等整体错误仍上报并回滚，不吞掉异常或把坏配置当空值。
进程重建不自动重放已接收或结果未知的输入。

## 快照退役

Migration 193 将 schema 142 升为 143，移除 conversation_runtime_environment 与 runtime_environment_plan。
不读取、解密或校验旧快照内容和密钥；缺失记录、损坏 ciphertext 均不成为升级门槛。
保留队员配置、仍需使用的私有密钥、消息、原生绑定和历史 Run。历史 Run 的 environment 字段忽略，
其原有 Run 身份不改写；新 Run 不再序列化启动环境。不新增清理服务、环境 digest、确认、变化检测或生效状态系统。
旧 Agents 环境只读归档与手动迁移参考属于保存配置，继续保留。

## 界面

环境编辑器保留保存/放弃、JSON 校验、凭据遮蔽/查看和离页保护，不展示固定的环境生效说明。

不显示快照缺失/重置生效文案，不新增确认、待生效状态或强制重启引导。
