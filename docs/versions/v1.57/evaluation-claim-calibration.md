## 前后差异与不变边界

- scoring 2.3 / generic-task-v5 的声明评价仅保留逐指标判断。升级 scoring 2.4 / generic-task-v6：真实 Judge 返回逐条交付声明、原文位置、证据、支持／矛盾／未知及重要性，代码检查引用与来源类型并汇总声明项；原始模型输出与计算结果均保留。
- 产物事实与 Agent 自检声明分开。最终产物或独立 verifier 通过，不能代替 Agent 自检成功的执行凭据。复合命令的退出码 0 不自动证明子检查通过；证据缺失仍未知，不编造失败或成功。
- 一次性固定产物允许使用固定预期值核对，不要求独立实现另一套算法。此前失败但后来有效修复的检查不自动扣最终质量；未修复的验证不足与虚假声明仍分别评价。
- DEMO-106 新建 1.3.0 Case 目录，保持题目、两阶段修复责任及预算，补键枚举顺序和非空错误字符串断言；旧目录、准入证据及报告不改写。
- 受控 Runner 额外保留选中验证命令的有界原始凭据与摘要，供本地追查；不将原始私有凭据注入 Judge，不扩大 Outcome 的过程权限。
- 读取既有 Core monitoring 的隔离 Trial 前后快照，空前置人口与实际 Run 数相符时才归属 Token；成本保留上报／估算类型，无法归属或采集不全为未知。只在显式评测保存快照，不增普通用户字段。
- 质量权重 50/25/25、Case 权重、协作五细项与三组、关键条件及未知分母保持；通用集仍为 12 个 Case。运行健康与质量保持独立。

通过需全部硬检查、关键语义与专项条件满足，所有必需评分和协作项完成；已确认退化、未知或预算受阻不能放行。可测耗时、Run／A2A、命令及 Judge 资源凭据保留，未由来源提供的 Token／成本仍明确不可用，不能许诺产生不存在的数据。重复可靠性与独立保留集不从单轮通过推断。
