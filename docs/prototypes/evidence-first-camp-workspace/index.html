这个版本改变了什么

它保留当前 Camp 的领域边界和 Porcelain / Steel 世界，只改变用户第一眼看到的优先级。

  • 首层固定展示责任、待决定事项和最近证据，不再让消息数量定义页面。
  • 公共讨论仍是开放阅读面，Task、Approval、Run 不被伪装成聊天气泡。
  • 队员画像降为 28px 稳定身份记号，专业身份由职责、Runtime 与证据建立。
  • 去掉星芒、渐变 Hero、英文眉题和同尺寸卡片墙，状态色只表达真实语义。
