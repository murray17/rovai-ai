PROTOTYPE NOTE

Skill 身份色

复用生产现有的八种身份色与 FNV-1a 算法。唯一输入是创建时的稳定 Skill UUID；名称、Revision、来源和开关状态都不会改变颜色。

fnv1a32(skill.id) % 8 + 1 → --identity-n

来源标签保持简短。 图标颜色回答“这是哪个 Skill”；标签只显示 Rovai、GitHub 或用户导入，完整来源、仓库与 Revision 都进入详情。
