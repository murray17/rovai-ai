# 定时任务布局交互稿 v34

基于用户提供的 v30 HTML，延续 v31 / v32 的布局调整，供本轮交互确认。当前文件为 `rovai-scheduled-tasks-prototype-v34.html`。单文件使用内存示例数据，刷新后重置；不会创建真实任务或执行模型。

- 初始总览与当前记忆页相同：外层最大 1136px 居中，内边距 28px。
- 点击已有任务、模板或新建后，占满导航右侧的可用内容区。
- 首页保留与记忆页一致的英文页眉 `Automation / Scheduled`。
- 列表默认 248px，可拖至最小 208px；全部、开启、关闭、新建紧贴顶部同一行，没有返回箭头或额外标题空行。
- 新建直接显示空白表单。右下角为“保存”，填写执行内容后可以模拟保存，名称可留空。
- 时间选择保留原稿的小时 / 分钟分栏、加减按钮与快捷时间，统一字号、间距和选中状态；支持直接输入、方向键调整、Enter / 完成收起、Escape 收起并返回触发按钮。
- 日期日历、星期和重复频率选项同步调整为与表单一致的尺寸。
- Cron 输入时校验五段格式、字段范围和表达式语法，错误就地展示；无效表达式禁止新建保存及已有任务的自动保存，修正后恢复。已有任务校验失败时保留草稿，并阻止切换页面丢失输入。
- 队员和运行项目先一起收缩；每组约 280px 仍可并排，再窄时自动换为两行，每个选择框都延伸到右边缘。
- 运行时间、通知到渠道和执行历史始终与提示词框等宽；宽屏表单最大 1440px。
- 右上角关闭回到居中总览。分隔条支持拖动、方向键、End 收起、Home 最小 208px、Enter / 双击恢复默认 248px。

v31 已验证任务入口、模板入口、直接新建、模拟创建及返回总览。v32 已在 2560×1440、1440×920、1140×920、1100×920 和 1040×920 验证等宽与换行：1140px 时两组继续并排，1100px 时换行后均贴齐右边缘，没有横向溢出。

v33 内联脚本语法检查通过。在 1440×1000、1040×920、2560×1440 检查时间弹层、日历和表单布局，无横向溢出；验证空提示词禁用保存、留空名称保存、快捷时间、直接输入、键盘调整、23:55 加五分钟变为 00:00、日期切月选择、每周选择、模板入口以及返回总览。

v34 复现了 `600 9 * * *` 无报错且可保存的问题。修复后验证输入标记无效、范围提示、禁用保存、修正恢复、正常保存、已有任务无效草稿不写回及离开前校验。1040px 和 2560px 窗口无横向溢出；内联脚本语法检查和 4 项校验回归测试通过。

v34 内联打包 `cron-parser` 5.10.0 和 Luxon 3.7.2，用于表达式校验，离线打开也可用。原型校验源码为 `cron-validation.mjs`，第三方 MIT 许可保留在 HTML 中。运行 `node --test docs/prototypes/scheduled-tasks-responsive/cron-validation.test.mjs` 检查实际嵌入 HTML 的校验器。

Cron 组件调研：`react-js-cron` 提供成品编辑器，但当前版本依赖 Ant Design 6。当前沿用自有控件，只引入解析校验；后续可用 `cRonstrue` 输出中文说明。生产实现仍须以 Core 的五段 Cron 校验与求值为准，此 HTML 不调用 Core。
