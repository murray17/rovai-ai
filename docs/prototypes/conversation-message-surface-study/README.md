# Rovai-ai conversation message surface study

This one-off study compares three ways to unify user and Agent message surfaces without assigning a background color to each Agent.

- [`shared-reading-plane.html`](./shared-reading-plane.html) — recommended open reading plane.
- [`narrative-artifact-width.html`](./narrative-artifact-width.html) — narrow narrative with wider work artifacts.
- [`uniform-neutral-sheets.html`](./uniform-neutral-sheets.html) — identical neutral sheets for every speaker.

The pages are self-contained and make no network, Core, Shell, or Runtime calls. The product shell and fixture are intentionally identical so only the message grammar changes.
