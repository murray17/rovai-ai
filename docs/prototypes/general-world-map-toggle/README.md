# 通用设置 · 世界地图开关交互稿

打开 [`index.html`](index.html) 可查看独立 HTML 交互稿。原型沿用 Rovai AI 当前的
Porcelain Day / Steel Night、270px 导航轨、设置页 1040px 内容轨，以及会话阅读面右上角的
“会话 / 地图”切换器。

本稿用于评审以下设计提案：

- 保留当前“启动”和“新对话”的生产结构，在“新对话”和“窗口”之间增加“会话”区块；
- “世界地图”Switch 初始开启并立即保存，但不显示“默认开启”标签；
- “窗口”右侧继续使用安静的白色 / raised 承载框；
- 关闭时，已经处于地图的会话立即回到会话时间线；
- 会话页保留可发现的“地图”入口，但将其呈现为不可用状态；点击或键盘激活只解释原因，
  不进入地图，并提供“前往通用设置”的恢复路径；
- 原型支持日间 / 夜间、键盘 Focus、Reduced Motion、1040×700 与 1440×920 评审尺寸。

页面中的消息、队员和状态均为合成样例；地图底图复用 Renderer 当前的只读产品资产。该原型不是
生产实现、领域合同或验收证据。
