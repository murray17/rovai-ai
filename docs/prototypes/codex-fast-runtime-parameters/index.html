设计判断

Fast 是受支持模型上的 run-scoped service tier，不是模型身份，也不是权限。它因此位于“运行参数”中，排在模型与推理强度之后；只有当前 Codex 模型目录明确广告该档位时才可选择。示例倍率依据 OpenAI 官方 Speed 文档。
