# Porcelain Gray 来源研究

[`rovai-porcelain-gray-study.html`](./rovai-porcelain-gray-study.html) 是 P0–P4 侧栏材质与 Steel 配色的早期对比研究，最终选择为 `P2 Neutral`。它保留在项目中用于追溯视觉来源，不是当前 Renderer 的页面结构、产品文案或交互合同。

当前会话最终累计的完整交互原型是 [`renderer-p2-empty-camp/rovai-p2-empty-camp.html`](../renderer-p2-empty-camp/rovai-p2-empty-camp.html)。队员页与记忆页都在该单一 HTML 中；生产约束仍以 [`docs/ui/README.md`](../../ui/README.md)和当前 Renderer 代码为准。
